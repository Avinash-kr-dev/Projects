# 🚀 Web Development Practice Projects

A curated collection of interactive HTML, CSS, and JavaScript projects designed to practice and master core web development concepts. Each project focuses on specific skills, from DOM manipulation to form handling and real-time updates.

**🌐 Live Demo:** [https://avinash-kr-dev.github.io/Projects/](https://avinash-kr-dev.github.io/Projects/)

---

## 📋 Projects Included

### 1. **Color Scheme Switcher** 🎨
Interactive color picker that changes the page background on click. Perfect for learning event handlers and DOM manipulation.
- **Skills:** Event listeners, DOM selection, CSS color properties
- **Location:** `One-Color Changer/`

### 2. **BMI Calculator** ⚖️
Calculate Body Mass Index with input validation and weight categorization. Includes a helpful guide for healthy BMI ranges.
- **Skills:** Form handling, input validation, mathematical operations, conditional logic
- **Location:** `Two-BMICalculator/`

### 3. **Digital Clock** ⏰
Real-time clock display showing your local time with responsive, modern styling.
- **Skills:** Date/Time API, setInterval, DOM updates, CSS styling
- **Location:** `Three-DigitalClock/`

### 4. **Guess the Number** 🎮
Interactive number guessing game with 10 attempts. Provides feedback (too high/too low) and tracks previous guesses.
- **Skills:** Random number generation, form submission, conditional logic, game state management
- **Location:** `Four-GuessTheNumber/`

### 5. **Event KeyCodes** ⌨️
Displays key information (name, code, keyCode) when you press any keyboard key. Great for understanding keyboard events.
- **Skills:** Keyboard events, event object properties, DOM manipulation
- **Location:** `Five-Keyboard/`

### 6. **Background Color Changer** 🌈
Auto-generates random background colors on a timer. Includes start/stop controls for dynamic practice with setInterval.
- **Skills:** Random color generation, setInterval/clearInterval, button event handling
- **Location:** `Six-unlimitedColor/`

### 7. **To-Do List App** ✅
Full-featured task manager with add, delete, and persistent storage capabilities. Demonstrates practical DOM manipulation and data management.
- **Skills:** Array manipulation, DOM creation/removal, local storage, event delegation
- **Location:** `to-do app/`

## 🛠️ Tech Stack

- **HTML5** – Semantic markup and form elements
- **CSS3** – Modern styling, flexbox layouts, responsive design
- **Vanilla JavaScript** – ES6 features, DOM API, event handling

**No frameworks or build tools** — pure, foundational web development.

## 🚀 Quick Start

### View the Projects
1. Visit the **[live site](https://avinash-kr-dev.github.io/Projects/)** hosted on GitHub Pages
2. Or clone this repository and open `index.html` in your browser:
   ```bash
   git clone https://github.com/Avinash-kr-dev/Projects.git
   cd Projects
   open index.html  # macOS
   # or
   start index.html  # Windows
   ```

### Running Locally
No build process required! Simply:
1. Open any `index.html` file in your browser
2. Each project is self-contained with its own `script.js` and `style.css`

## 💡 Tips for Learning

1. **Explore the Code** – Open `script.js` in each project to understand implementation patterns
2. **Modify & Experiment** – Change colors, difficulty levels, or add new features
3. **Use DevTools** – Inspect elements, debug, and watch event firing in real-time
4. **Read the HTML** – Notice semantic structure and accessibility considerations (e.g., `aria-current="page"`)
